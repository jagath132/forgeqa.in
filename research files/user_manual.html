ForgeQA End-to-End Operating Guide

Welcome to ForgeQA — the AI-powered QA automation platform that transforms requirements, PRDs, and user stories into structured test cases, automated Playwright/Cypress scripts, and CI/CD regression suites.

01. Product Overview & Core Concepts

ForgeQA accelerates quality assurance by automating the end-to-end testing workflow. Instead of manually parsing requirements and writing test scripts line by line, ForgeQA leverages Retrieval-Augmented Generation (RAG) to generate domain-aware test cases directly grounded in your project documents.

🔍 1. RAG-Powered Ingestion

Upload PRDs, architecture PDFs, Excel sheets, and UI screenshots. The platform embeds context to produce zero-hallucination test suites.

🤖 2. 6-in-1 Multi-LLM Provider

Select from Google Gemini 2.0, OpenAI GPT-4o, Claude 3.5 Sonnet, Groq LLaMA 3.1, OpenRouter, and OpenCode with custom BYO API keys.

💻 3. 100% Code Ownership

Export native Playwright, Cypress, Selenium, or Appium code in TypeScript, JavaScript, Python, Java, or C#. Zero vendor lock-in.

🚀 4. Automated Regression Runs

Upload APK or ZIP build artifacts and trigger automated regression suites on every build commit using CI/CD webhooks.

02. Account Registration & Onboarding

Follow this step-by-step journey to create your workspace and configure your environment.

1

Create your Account

Navigate to https://forgeqa.in/register. Enter your full name, work email address, and set a strong password (minimum 8 characters, uppercase, lowercase, digit, and special symbol).

2

Select Subscription Tier & Product Key

Choose between Free (50 test cases/month), Pro (500 cases + multi-LLM access), or Enterprise. Enter your product activation key received via email.

3

Verify Email & Complete Onboarding

Click the verification link sent to your email. Upon your first login, a guided interactive tour will introduce your main dashboard.

03. Configuring AI Providers & API Keys

ForgeQA allows you to bring your own API key (BYOK) for complete cost control and privacy. Your API keys are encrypted at rest using AES-256-GCM.

🔐
Security Note: API keys are decrypted in-memory only during generation requests. They are never logged or exposed in client responses.

Supported Providers & Key Setup Steps:

1

Navigate to Settings

Click on Settings ➔ AI Provider tab in the sidebar navigation menu.

2

Select Provider & Input Key

Select your desired active provider (e.g., Google Gemini or OpenAI) from the dropdown. Paste your secret key.

3

Save & Test Connectivity

Click Save API Key. The status indicator will turn green (Configured & Active).

04. Knowledge Base & RAG Ingestion

The Knowledge Base equips the AI with your project's specific business rules, terminology, and workflows.

Supported Document Formats

File Format Extension Parser Engine Max Size
PDF Document .pdf pdf-parse 25 MB
Word Document .docx mammoth 25 MB
Text & Markdown .txt, .md Direct UTF-8 read 25 MB
Excel & CSV .xlsx, .csv xlsx library / csv-parse 25 MB
UI Screenshots .png, .jpg, .webp Tesseract.js OCR 25 MB
SharePoint Link .sharepoint.com URL HTTPS Document Stream N/A
⚠️
Upload & File Limits:
  • Maximum File Size: 25 MB per individual file.
  • Maximum Batch Upload: Up to 12 files per single upload request.
  • JSON API Request Body Limit: 512 KB.
💡
Pro Tip: Upload both your PRD text document AND UI design screenshots together. ForgeQA's RAG pipeline will cross-reference functional requirements with visual UI components!

05. AI Test Case Generation & Suite Management

Generate structured test cases in under 2 minutes using streaming Server-Sent Events (SSE).

1

Enter Requirement Text

Go to Generator. Paste your requirement or feature description (minimum 10 characters).

2

RAG Auto-Retrieval

ForgeQA searches your uploaded Knowledge Base for relevant chunks, displaying cosine similarity relevance scores (e.g., 95% match).

3

Real-Time Streaming Output

Test cases appear token-by-token in real time, automatically organized into Positive, Negative, Edge Case, and Validation categories.

Managing Test Suites

Organize generated test cases into color-coded suites (e.g., Smoke Tests, Regression Suite, or Sanity Suite). You can export suites to PDF, Excel, or JSON format at any time.

06. Automation Script Generation & CI/CD

Convert your test cases into executable automation scripts for major testing frameworks.

1

Select Test Cases & Target Framework

Choose test cases from your suite and select your target framework: Playwright, Cypress, Selenium, or Appium.

2

Configure Options & Language

Select your language (TypeScript, JavaScript, Python, Java, C#), viewport size (1920x1080), and target application URL.

3

Download & Integrate

Copy or download the generated script file. Run directly on your machine or commit to your git repository.

Setting up CI/CD Webhooks

To run regression tests on every build automatically:

# Sample GitHub Actions Workflow Integration (.github/workflows/regression.yml)
name: ForgeQA Triggered Regression Run
on: [push]
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout Code
        uses: actions/checkout@v3
      - name: Trigger ForgeQA Regression Webhook
        run: |
          curl -X POST "https://forgeqa.in/api/regression/builds/webhook" \
               -H "Content-Type: application/json" \
               -d '{"platform": "Web", "commit": "${{ github.sha }}"}'

07. Security, Admin Audit Logs & FAQs

Account Security & 2FA Setup

Enable Two-Factor Authentication (TOTP) under Settings ➔ Security. Use Google Authenticator or Authy to scan the QR code. You can also monitor active trusted devices and revoke sessions remotely.

Admin Audit Logs

Admins can review system-wide audit trails, tracking user sign-ins, key modifications, subscription changes, and IP addresses for full compliance.

Frequently Asked Questions (FAQ)

?

Q: Are my uploaded documents used to train public AI models?

A: No. ForgeQA uses direct API endpoints with zero data retention policies. Your documents remain strictly private in your enterprise tenant.

?

Q: What is the maximum file size limit for uploads?

A: The maximum file size limit is 25 MB per file, with a maximum of 12 files per batch upload. Files exceeding 25 MB will return a 413 Payload Too Large error.

?

Q: Can I run generated Playwright scripts without a ForgeQA subscription?

A: Yes! Generated scripts are 100% open native code. Once downloaded, they belong to you and require no ongoing ForgeQA license to execute.
