ForgeQA Module Overview Slide 2 of 8
Test Matrix Generator

AI Test Case Generator (/generator)

Categorized Test Cases
  • Positive Cases: Standard successful user paths
  • Negative Cases: Error conditions & invalid inputs
  • Validation Checks: Boundary lengths & format constraints
  • Edge Cases: Unusual scenarios & extreme inputs
  • Schema Fields: Test Case ID (TC_001...), Summary, Test Steps, Expected Result, Status
Export & History Management
  • Excel Export (.xlsx): Download structured spreadsheet matrices
  • PDF Export (.pdf): Generate printable test specification documents
  • Word Export (.docx): Download formatted Word documentation
  • Persistent History: Stores up to 50 generation runs per user
  • Quick Reload: Instant retrieval & deletion of historical runs

Knowledge Base

RAG Knowledge Base & Document Processing (/knowledge)

Supported Documents & Uploads
  • PDF Documents (.pdf): Analyzed via server pdf-parse
  • Word Files (.docx): Converted via Mammoth parser
  • Text & Markdown (.txt, .md): Raw spec ingestion
  • SharePoint Sync: Integration for shared team documents
  • Image OCR: Tesseract.js image text extraction
Semantic Chunking & AI Context
  • Chunking Pipeline: Processing → Needs Chunking → Ready
  • Relevance Scoring: Rank-scores chunks against input requirements
  • Grounded Generation: AI references internal documentation during test creation
  • File Storage: Document metadata & chunks stored in MongoDB
